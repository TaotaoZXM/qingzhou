# Cal 页面设计规格

## 目标

在轻舟现有的 Start、To-do、Done 之外增加同级页面 Cal，用月历作为日期入口，查看某一天的完成任务、任务复盘和灵感。页面保持现有手机端视觉语言，不引入新的登录或后端依赖。

## 页面结构

- 顶部沿用应用栏：应用名“轻舟”和账户入口保持现有样式。
- 底部导航增加第四项“Cal”，与 Start、To-do、Done 平级；现有三项位置和行为保持不变。
- Cal 页面主体分为两段：
  - 月历区：显示当前月份完整月视图，星期从周日开始；提供上一个月、下一个月按钮；当前日期有轻量标识，选中日期有明确但克制的选中态。
  - 当日记录区：显示选中日期，并按“完成任务”“任务复盘”“灵感”三个分类展示内容；每个分类沿用 To-do 的列表行结构，空分类显示安静的空状态。

## 日历行为

- 默认打开 Cal 时选中今天。
- 点击某个日期后，更新当日记录区，不刷新页面。
- 月份切换只改变月历和选中日期；切换月份时选中该月第一天，若当前日期仍在新月份则保留当前日期。
- 月历补齐上月末尾和下月开头的日期格，但这些日期可见且不可选，避免把记录归属混淆到当前月份。
- 有记录的日期显示小圆点；记录类型不在日历格内展开，详情只在下方显示。

## 数据与兼容

- Todo 使用已有 `deadline` 日期作为日期归属；无截止日期的进行中任务不出现在 Cal 的完成任务区。
- Done 使用已有 `completed` 时间戳作为完成日期归属，显示当天完成的任务。
- 复盘使用所属 Done 任务的完成日期归属；已完成复盘显示复盘内容，待复盘显示“点击打开复盘”。
- 灵感从纯字符串升级为带 `createdAt` 的对象：`{ text, createdAt }`。新记录保存创建时间，并按创建日期显示。
- 读取旧版字符串灵感时，兼容转换为当天记录，不丢失原有文字；保存时统一写回新对象格式。
- `localStorage` 和现有 Supabase 状态同步继续使用同一份应用状态，不改变已有任务和复盘数据结构的兼容字段。

## 视觉与字号

- 延续现有轻量、留白、细分隔线和绿色强调色。
- 月份标题、日期网格和当日标题保持清晰层级，不使用装饰性大卡片。
- 任务名称沿用当前统一字号 `14px`，任务详情沿用 `13px`；分类标题与筛选/辅助文字沿用 Done/To-do 的层级。
- Cal 底部导航文字字号与现有导航保持一致，图标使用现有文本图标风格，避免引入新图标库。

## 验收标准

- Cal 出现在底部导航，能与其他三个页面互相切换。
- 默认显示当月月历并选中今天，前后月份可以切换。
- 点击日期后，完成任务、任务复盘、灵感三类内容只显示该日期的数据。
- 日历有记录的日期有标识，无记录日期不显示误导性标识。
- 新增灵感后能在当天 Cal 中看到，刷新页面后仍保留；旧版灵感仍可显示。
- 勾选需要复盘、完成复盘后，Cal 对应日期的复盘内容同步更新。
- `node --check`、`git diff --check` 和 Playwright 页面交互验证通过，控制台无错误。
